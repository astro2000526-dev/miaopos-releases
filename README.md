# 妙手宝 MiaoPOS · 安装包

按摩、足疗、SPA 门店用的收银应用。这里只放安装包，最新版在 [Releases](../../releases/latest)。

## 安装

1. 在收银机或安卓平板（Android 7.0 及以上）上打开 [Releases](../../releases/latest)，下载 `miaopos-vX.Y.Z.apk`
2. 点开下载的文件安装；系统提示不允许安装未知应用时，按提示允许
3. 打开妙手宝，按向导建店

## 更新

装好之后不用再来这里。应用每天自己查一次新版本，也可以在「设置 › 软件更新」里手动检查、下载、安装。
门店的数据都留在本机，更新不会动它；安装新版之前应用会自动备份一份。

没有网络的门店：把新版 APK 拷到机器上，在「设置 › 软件更新 › 从文件更新」里选它。

## 核对文件

每个版本都附带 `.sha256`，下载后可以核对：

```
sha256sum miaopos-vX.Y.Z.apk
```

**English** — MiaoPOS is a point-of-sale app for massage and spa shops. Download the latest APK from
[Releases](../../releases/latest) and install it on a device running Android 7.0 or later. After that the app
checks for new versions by itself (Settings › Software update). Shop data stays on the device.

**ไทย** — MiaoPOS คือแอปแคชเชียร์สำหรับร้านนวดและสปา ดาวน์โหลด APK เวอร์ชันล่าสุดได้ที่
[Releases](../../releases/latest) แล้วติดตั้งบนอุปกรณ์ Android 7.0 ขึ้นไป หลังจากนั้นแอปจะตรวจสอบเวอร์ชันใหม่เอง
(ตั้งค่า › อัปเดตซอฟต์แวร์) ข้อมูลของร้านเก็บอยู่ในเครื่องเท่านั้น
